## HIA — 파일 기반 업무 기억

- 작업 시작 시 프로젝트의 HIA-RULES.md와 STATE.md를 읽는다.
- 관련 결정, 최근 로그, 원본은 현재 작업에 필요한 부분만 추가로 읽는다.
- 중요한 결정·산출물·검증·중단은 logs/의 작업별 파일에 기록한다.
- 답변 전 최신 상태를 다시 읽고 STATE.md를 갱신한다.
- 제안 / 사용자 확정 / 실행 / 검증을 구분한다.
- 다른 작업자의 진행 상황과 기존 프로젝트 규칙을 보존한다.
- 사용자의 현재 요청과 상위 지침이 우선한다.
