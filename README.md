# 한이룸의 인텔리전스 에이전트(HIA)

세션이 끝나도, AI가 바뀌어도 이어지는 파일 기반 업무 기록 방식입니다.

## 시작하기

[HIA 설치·사용 가이드](HIA-Guide.md) 하나로 설치 요청문, 전체 템플릿, 인수인계 실습을 확인할 수 있습니다.

1. 작업할 프로젝트를 Codex 또는 Claude Code에서 엽니다.
2. 가이드를 전달하고 3장의 설치 요청문을 보냅니다.
3. 5장의 새 세션 인수인계 시험을 진행합니다.

## hia-start 스킬

`skills/hia-start` 폴더 전체를 아래 사용자 스킬 폴더에 복사합니다. 같은 이름이 이미 있다면 기존 내용을 확인하고 백업한 뒤 병합하세요.

| 도구 | 설치 위치 | 호출 |
|---|---|---|
| Codex | `~/.agents/skills/hia-start` | `$hia-start` |
| Claude Code | `~/.claude/skills/hia-start` | `/hia-start` |

설치 후 스킬이 보이지 않으면 새 세션 또는 앱 재시작 후 확인합니다. 스킬은 호출한 현재 프로젝트의 기존 기록을 보존하며 HIA를 적용합니다.

## 구성

- `HIA-Guide.md`: 단일 파일 설치·사용 안내
- `skills/hia-start/SKILL.md`: 프로젝트 적용 절차
- `skills/hia-start/assets/`: 지침·현재 상태·결정·로그 템플릿

상황 변화 기록은 지침을 읽고 작업하는 AI가 수행합니다. 백그라운드 감시, 외부 서비스 연결, 예약 실행, 클라우드 백업이 자동 설치되지는 않습니다.

## 검증 범위

가이드 템플릿과 파일 연결, 스킬 형식을 점검했습니다. 각 사용자 환경의 새 세션·교차 모델 인수인계는 가이드의 실습으로 별도 확인해야 합니다.

개인 활동 기록, 운영 백업, 인증 정보, 별도 영상편집 프로젝트는 이 저장소에 포함하지 않습니다.
